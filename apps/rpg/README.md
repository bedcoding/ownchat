# @ownchat/rpg

웹툰 한 회차를 **선택지 트리 한 편**으로 만드는 게임 + 그 트리를 만드는 관리자 저작 도구.

목표를 달성하면 다음 화로 넘어간다. 1화 → 2화 → 3화가 자동으로 이어진다.

```bash
npm run rpg          # 저장소 루트에서. localhost:3200
```

## 핵심 전제: 플레이 중에는 AI가 돌지 않는다

```
관리자 (저작 시점, AI 1회)          플레이어 (런타임, AI 0회)
회차 이미지 → 요약 → 트리 초안   →   발행된 트리를 걷기만 한다
       ↓ 사람이 고치고 발행
```

이 구조에서 나오는 것들:

| | |
|---|---|
| 런타임 AI 비용 | **0** |
| 오프라인 | 플레이 화면은 비행기 모드에서도 돈다 |
| 검수 | 모든 문장이 고정이라 작가·법무 검수가 가능하다 |
| 치팅 | 자유 입력이 없어서 "즉시 완료" 같은 우회가 불가능하다 |
| 등급 | 사전 생성 + 사람 검수라 서빙 정책을 자체 등급으로 정한다 |

## 화면 둘

- **`/play`** — 플레이어. 장면 컷 + 서술 + 선택지 + 하단 능력치 바. 순수 클라이언트라 네트워크 호출이 없다
- **`/admin`** — 관리자. 작품·회차·노드 편집, 미리보기, JSON 내보내기/가져오기, 발행

요구치가 모자란 선택지는 **숨기지 않고 잠긴 채로 보여준다**. "저 길이 있다는 건 알지만 지금은 못 간다"가 재플레이 동기가 된다.

## 플랫폼 이름

시나리오 텍스트에는 `{PLATFORM}` 토큰만 커밋되어 있다. 실제 이름은 gitignore 되는 `.env.local` 에서 주입하고, 없으면 가상 이름으로 떨어진다.

```bash
cp .env.local.example .env.local
```

## 구조

```
app/play/     트리 러너 (플레이어 + 관리자 미리보기가 공유)
app/admin/    저작 도구
lib/types.ts  데이터 모델 (전부 JSON 직렬화 가능)
lib/engine.ts 판정·전환·검증 (순수 함수)
lib/brand.ts  플랫폼 이름 치환
data/         번들 샘플 작품
```

저장은 localStorage. 기기 간 이동은 관리자 화면의 JSON 내보내기/가져오기로 한다.

## 알아둘 것

- **dev 서버가 깨진 중간 저장 상태를 캐시한다.** `tsc` 와 `next build` 가 통과하는데 브라우저만 빈 화면이면 `.next` 를 지우고 다시 띄운다
- 실제 작품 이미지·미공개 회차 정보는 커밋하지 않는다 (`data/local/`, `public/uploads/` 는 gitignore)
